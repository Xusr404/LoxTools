# Changelog

All notable changes to LoxTools are documented in this file.

The project uses Semantic Versioning and supports `alpha`, `beta`, `rc`, and stable releases.

## [Unreleased]

## [1.1.1] - 2026-10-30

### Added

- First-run guidance for accessing LoxTools from the system tray.
- Installation folder modes and automatic registration of successful installation paths.

### Changed

- Refined Settings and Version Selector layouts and button styling.
- Improved download cancellation, installation progress, installer monitoring, and cleanup.
- Expanded English and German translations.

### Fixed

- Preserve existing files when downloads or installer extraction fail.

## [1.1.0] - 2026-06-21

### Added

- Automatic LoxTools update checks with stable, beta, and alpha channels.
- Update controls and progress information in Settings and the tray.
- English and German installer support.

### Changed

- Improved and reduced installer contents while retaining the included .NET runtime.
- Updates can download and install silently, then restart LoxTools automatically.

### Security

- Downloaded updates are verified before installation.

## [1.0.0] - 2026-06-19

### Added

- Initial public release of LoxTools.
